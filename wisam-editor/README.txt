WISAM CODE EDITOR - محرر أكواد وسام
=====================================

هذا التطبيق هو محرر أكواد متكامل للغة برمجة وسام (Wisam Programming Language).

المميزات:
---------
✨ محرر أكواد متقدم مع تلوين الصياغة
🔧 إكمال تلقائي للكلمات المفتاحية
📁 مستكشف ملفات متكامل
🎨 وضع داكن/فاتح
📱 تصميم متجاوب
💾 تطبيق ويب تقدمي (PWA)

كيفية الاستخدام:
----------------
1. افتح ملف index.html في متصفح حديث
2. أو انشر الملفات على خادم ويب
3. يمكن تثبيت التطبيق على الجوال كـ PWA

للبناء كـ APK (Android):
-------------------------
1. ثبت Android Studio: https://developer.android.com/studio
2. افتح مجلد android/ في Android Studio
3. انتظر حتى يتم مزامنة Gradle
4. اذهب إلى Build > Build Bundle(s) / APK(s) > Build APK(s)
5. سيجدد APK في: android/app/build/outputs/apk/debug/

ملاحظة: يتطلب بناء APK:
- Android SDK
- Java JDK 17+

---

This is a code editor for the Wisam Programming Language.

Features:
---------
✨ Advanced code editor with syntax highlighting
🔧 Auto-completion for keywords
📁 Integrated file explorer
🎨 Dark/Light mode
📱 Responsive design
💾 Progressive Web App (PWA)

How to use:
-----------
1. Open index.html in a modern browser
2. Or deploy files to a web server
3. Can be installed as PWA on mobile

To build APK (Android):
-----------------------
1. Install Android Studio
2. Open android/ folder in Android Studio
3. Wait for Gradle sync
4. Go to Build > Build Bundle(s) / APK(s) > Build APK(s)
5. APK will be at: android/app/build/outputs/apk/debug/

Requirements for APK build:
- Android SDK
- Java JDK 17+
