# Contributing to Wisam / المساهمة في وسام

First off, thank you for considering contributing to Wisam! 🎉

شكراً لاهتمامك بالمساهمة في لغة وسام! 🎉

## 🚀 Ways to Contribute / طرق المساهمة

### 1. Reporting Bugs / الإبلاغ عن الأخطاء
- Use the [GitHub Issues](https://github.com/droy-go/wisam/issues) page
- Include a clear description and steps to reproduce
- Include your environment details (OS, compiler, etc.)

### 2. Suggesting Features / اقتراح الميزات
- Open a feature request issue
- Describe the feature and its use case
- Provide examples if possible

### 3. Code Contributions / المساهمات البرمجية
1. Fork the repository
2. Create a new branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Run tests (`make test`)
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## 🛠️ Development Setup / إعداد بيئة التطوير

```bash
# Clone the repository
git clone https://github.com/droy-go/wisam.git
cd wisam-lang

# Build the project
make

# Run tests
make test

# Run interactive shell
make shell
```

## 📋 Code Style / نمط الكود

- Use 4 spaces for indentation
- Follow existing code style
- Comment your code in Arabic or English
- Keep functions focused and small

## 🧪 Testing / الاختبار

Before submitting a PR:
- Run `make test` to ensure all tests pass
- Test on multiple platforms if possible
- Add tests for new features

## 📚 Documentation / الوثائق

- Update README.md if needed
- Add comments to complex code
- Update examples if API changes

## 🙏 Thank You! / شكراً!

Your contributions make Wisam better for everyone! 💙

مساهماتكم تجعل وسام أفضل للجميع! 💙
