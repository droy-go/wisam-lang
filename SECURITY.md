# Security Policy / سياسة الأمان

## Supported Versions / الإصدارات المدعومة

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability / الإبلاغ عن ثغرة أمنية

If you discover a security vulnerability in Wisam, please report it responsibly:

إذا اكتشفت ثغرة أمنية في وسام، يرجى الإبلاغ عنها بمسؤولية:

### 📧 Email / البريد الإلكتروني
Send details to: **security@wisam-lang.org**

### 📝 What to Include / ما يجب تضمينه
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

### ⏰ Response Time / وقت الاستجابة
- Acknowledgment within 48 hours
- Initial assessment within 5 days
- Fix timeline will be communicated

## Security Best Practices / أفضل ممارسات الأمان

When using Wisam:
- Don't execute untrusted code
- Validate all inputs
- Use latest version
- Report suspicious behavior

Thank you for helping keep Wisam secure! 🔒

شكراً لمساعدتك في الحفاظ على أمان وسام! 🔒
